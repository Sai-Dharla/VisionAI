MobileNetV2 Technical Specs

Deep Learning architecture details and inference benchmarks.

🤖 Model Architecture

  • • Framework: TensorFlow 2.x / Keras
  • • Model: MobileNetV2 (Pre-trained on ImageNet)
  • • Parameters: ~3.4 Million weights
  • • Input Dimensions: 224 × 224 × 3 (RGB)
  • • Output: 1,000 Class probabilities + Softmax

⚡ Backend & Performance

  • • Server: Django Web Framework (Python 3.12)
  • • Image Processing: Pillow (PIL) preprocessing
  • • Inference Latency: ~15ms - 40ms CPU per image
  • • Metadata Enrichment: Wikipedia API integration
  • • Storage: SQLite database for account scan records
